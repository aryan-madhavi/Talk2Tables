↳ WRITE_OP branch
UPDATE / INSERT / DELETE returns a preview with risk level and estimated affected rows. Frontend shows a confirmation dialog — execution only happens on explicit approval via a separate /execute endpoint.
↳ CLARIFY branch
When the query is ambiguous, the LLM returns a clarifying question instead of SQL. The question is sent back to the user, and the answer feeds into the next turn's context.
↳ RETRY branch
If validation fails, the agent retries up to 2 times — passing the specific error reason back to the LLM so it can self-correct. After 2 failures, a structured error is returned to the frontend.
